# Heart Disease Prediction Using Machine Learning

Preventing heart disease is very important today. This project uses machine learning to predict whether a person has heart disease or not.

The heart disease dataset from Kaggle was cleaned and analyzed. Different classification models were trained and compared to find the best one for prediction.

What is new in this project is the web application. The best machine learning model was integrated into a Flask-based web app, where users can enter their medical details and check whether the result is positive or negative for heart disease. This makes the project simple to use and closer to real-world applications.

The following algorithms were implemented and compared:

* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* Logistic Regression

Performance metrics such as accuracy, precision, recall, and confusion matrix were used to evaluate each model.

This work was initially developed as a Jupyter Notebook ,Visual Studio and used in my Kaggle kernel titled
Binary Classification with Sklearn and Keras.

## 🚀 New Enhancements (Added Work)

After training and evaluating multiple models, the **best-performing model** was selected and deployed as a **web-based application** to make the system practical and user-friendly.

### Web Application Features:

* Built using **Flask (Python)** as the backend
* **HTML & CSS** used for frontend design
* Patients can **enter their medical details** through a web form
* The system predicts whether the result is **Positive or Negative for heart disease**
* Displays the **nearest hospital location** to assist users in seeking immediate medical help

### Technologies Used:

* Python (Flask, Scikit-learn)
* HTML, CSS
* Machine Learning Models
* Jupyter Notebook (for model development)

## 🎯 Conclusion

This project not only focuses on accurate heart disease prediction using machine learning but also bridges the gap between model development and real-world usability by deploying the best model as a web application. The system provides quick predictions and actionable insights, making it useful for both patients and healthcare support systems.
